# Tuya 3-Phase Meter (SPM02) Custom Integration

Integracja dla liczników energii Tuya 3-fazowych (model SPM02), bazująca na `tinytuya`.

## Instalacja

1. Stwórz folder `custom_components/tuya_3phase_meter` w swoim Home Assistant.
2. Skopiuj tam zawartość tego repozytorium.
3. Zrestartuj Home Assistant.
4. Przejdź do: Ustawienia -> Urządzenia oraz usługi -> Dodaj integrację.
5. Wyszukaj "Tuya 3-Phase Meter (SPM02)".
6. Wpisz swoje dane: IP urządzenia, Device ID oraz Local Key.
